Spatial Cell Proximity Explorer

Descriptive cell-type neighborhood counts from 2D spatial coordinates. Runs locally in your browser.

1. Input coordinates

CSV requires cell_id,cell_type,x,y. Use coordinates in one common unit (for example, µm); one row per cell or spot.

Quoted CSV fields are supported. No data are transmitted to a server.

Example data are loaded. Choose Analyze proximity.

2. Neighborhood results

All unordered pairs with Euclidean distance ≤ radius are counted once. This is not a ligand–receptor or statistical enrichment test.

Interpretation and privacy. Observed spatial proximity is descriptive; it does not establish cell–cell communication, directional signaling, significance, or causality. Cell-type labels and coordinate scale must come from a validated upstream workflow. Analysis and exports are entirely client-side; avoid using identifiable patient data in filenames or exports. Browser cap: 3,000 rows. The Python CLI handles up to 5,000.
